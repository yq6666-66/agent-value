# agent-value

[English](README.md)

给个人用的本地桌面工具（Tauri；当前须从源码构建，不提供安装包）。按成本、时间、质量给用户实际在用的（模型，路线）组合打分；三者权重按用户自己的偏好。不是公开排行榜：数字来自用户自己的任务，数据只留本机。打分规则依据仓外规范 v22 与决策记录；本 README 只写已实现部分。

## 问题

公开榜单和通用评测对不上「你自己在用的模型与路线」。需要在本机、按个人任务与偏好，比较臂（模型 + 路线）的性价比与真实性信号，而不是把数据交出去。

## 功能

1. **编程范围时间窗打分**：前沿、资格、推荐；展示真实性来源与权重来源。首窗可展示前沿但标「尚未校准」，不显示 V。档位阈值维持暂定；真实性未定、仅供参考。观测开跑与满窗校准已永久取消。
2. **臂**：列出 / 添加；查看数据库路径；导出；清空全部记录。
3. **五级自报向导**（权重 elicitation）；敏感性面板（胜者图、稳健标签、翻转句；首窗或无锚点层不显示图）。
4. **探针**：同意后记录；展示已记录 / 回放结果；同意后可手动跑一次；可启用应用内定时重跑（默认关；启用后等一个暂定间隔才首次发送；退出应用即停；不是 OS cron；开应用本身不发送；月预算停止会反映在面板）。
5. **指纹**：库可经 HTTP 采集官方直连指纹基线并写入本地 store（测试可用 mock）。桌面无一键采基线按钮。

## 技术

1. 核心库（Rust）+ 本地 SQLite store + Tauri 桌面外壳；网页视图不重算分数（外壳读 store、问 core）。
2. 探针 HTTP 轨与指纹采集库已合入；密钥只走环境变量名，不进仓。
3. 规范步骤 1–13 的判定侧已实现。打分主干如下（完整边界与实现细节以核心库及仓内长文档为准）。

一条臂在单元 \(u\) 上最多自试 \(K=3\) 次。记单次成功概率 \(p_1\)（Jeffreys–Beta 后验均值），失败后再试成功率为 \(\pi\)（由调用方传入）。则

$$
\begin{aligned}
q_K&=(1-p_1)(1-\pi)^{K-1},&
p_K&=1-q_K,\\
E[n_F]&=(1-p_1)\sum_{j=0}^{K-1}(1-\pi)^{j},&
E[n_W]&=E[n_F]-q_K .
\end{aligned}
$$

其中 \(p_K\) 为本臂 \(K\) 次内成功的概率，\(q_K\) 为全部失败后转交兜底臂的概率，\(E[n_F]\) 为本臂失败次数期望，\(E[n_W]\) 为重试前等待次数期望（不含「第 \(K\) 次失败后不再重试」那一次）。单元期望成本、活跃时间、交付质量。记臂为 \(i\)、单元为 \(u\)。

$$
\begin{aligned}
C^*_{iu}&=p_K\tilde C_S+E[n_F]\tilde C_F+q_K\,C^*_{F,u}+\frac{n^C\hat{\bar C}_C}{n^1+n^0},\\
T^*_{iu}&=p_K\tilde T_S+E[n_F]\tilde T_F+E[n_W]D+q_K\,T^*_{F,u}+\frac{n^C\bar T_C}{n^1+n^0},\\
Q^*_{iu}&=p_K\hat q+q_K\bar Q_F .
\end{aligned}
$$

自左至右依次为成功尝试、失败尝试、转交兜底、取消摊销（时间式另含重试间隔 \(D\)）。\(n^1,n^0,n^C\) 分别为成功、失败、取消次数；分母 \(n^1+n^0=0\) 时该单元对应维为 \(\mathrm{NA}\)。\(\tilde C_S,\tilde C_F\)（时间同理）为经缩尾并向基准收缩后的成功/失败侧均值；\(\hat{\bar C}_C,\bar T_C\) 为取消任务的平均成本/时间；\(\hat q\) 为本臂成功交付质量估计，\(\bar Q_F\) 为转交后由兜底完成的质量（向兜底单元质量收缩）。参照臂与兜底臂自身的转交项为 0。\(Q^*\in[0,1]\)。

层与总体对正权重单元、层做加权聚合得到 \(C^*,T^*,Q^*\)（任一正权重单元为 \(\mathrm{NA}\) 则聚合为 \(\mathrm{NA}\)）。价值分（即 \(V\)）用**聚合后**的值相对参照锚点 \(C^{\mathrm{ref}},T^{\mathrm{ref}},Q^{\mathrm{ref}}\)（参照臂的聚合值），且须 \(C^*,T^*,Q^*\) 三者均非 \(\mathrm{NA}\)：

$$
V=100\left(\frac{C^{\mathrm{ref}}+c_0}{C^*+c_0}\right)^{a}
\left(\frac{T^{\mathrm{ref}}+t_0}{T^*+t_0}\right)^{b}
\left(\frac{1-Q^{\mathrm{ref}}+\epsilon}{1-Q^*+\epsilon}\right)^{g}.
$$

\(V=100\) 与参照相当，更高更好。\(a,b,g\) 为成本/时间/质量的指数权重，\(a+b+g=1\) 且各项 \(\ge0.05\)（无依据时各取 \(1/3\)），来自五级自报。平滑常数 \(c_0=0.15\) 元、\(t_0=15\) 秒、\(\epsilon=0.02\)。首个评分窗可展示前沿但不显示 \(V\)（权重尚未校准）。档位阈值维持暂定；真实性未定、仅供参考（观测开跑与满窗校准已永久取消）。

## 用法

1. 从源码构建并运行桌面应用。先构建网页前端（可选示例：`npm ci` / `npm run build`），再在 `src-tauri/`（单独 Cargo 包）里 `cargo build`，或本地开发用 `cargo tauri dev` 后跑构建出的二进制。需要 Tauri 2 系统依赖（Linux：WebKitGTK 4.1 等）。当前不提供安装包。
2. 在应用内管理臂、跑自报 / 敏感性；同意后可手动跑一次探针或看回放，也可启用应用内定时重跑（见功能段）。
3. 可选示例：核心库检查 `cargo test --workspace`；探针 `cargo run -p agent-value-core --example probe_plan` / `probe_judge`。
4. 版本改动见 `CHANGELOG.md`；本 README 不含变更史。
