# agent-value

[English](README.md)

给个人用的本地桌面工具（Tauri；当前须从源码构建，不提供安装包）。按成本、时间、质量给用户实际在用的（模型，路线）组合打分；三者权重按用户自己的偏好。不是公开排行榜：数字来自用户自己的任务，数据只留本机。打分规则依据仓外规范 v22 与决策记录；本 README 只写已实现部分。

## 问题

公开榜单和通用评测对不上「你自己在用的模型与路线」。需要在本机、按个人任务与偏好，比较臂（模型 + 路线）的性价比与真实性信号，而不是把数据交出去。

## 功能

1. **编程范围时间窗打分**：前沿、资格、推荐；展示真实性来源与权重来源。首窗可展示前沿但标「尚未校准」，不显示 V。档位阈值维持暂定；真实性未定、仅供参考。观测开跑与满窗校准已永久取消。
2. **臂**：列出 / 添加；查看数据库路径；导出；清空全部记录。
3. **五级自报向导**（权重 elicitation）；敏感性面板（胜者图、稳健标签、翻转句；首窗或无锚点层不显示图）。
4. **探针**：同意后记录；展示已记录 / 回放结果；同意后可手动跑一次；可启用应用内定时重跑（默认关；启用后等一个暂定间隔才首次发送；退出应用即停；不是 OS cron；开应用本身不发送；月预算停止会反映在面板）。
5. **指纹**：库可经 HTTP 采集官方直连指纹基线并写入本地 store（测试可用 mock）。桌面无一键采基线按钮。

## 技术

1. 核心库（Rust）+ 本地 SQLite store + Tauri 桌面外壳；网页视图不重算分数（外壳读 store、问 core）。
2. 探针 HTTP 轨与指纹采集库已合入；密钥只走环境变量名，不进仓。
3. 规范步骤 1–13 的判定侧已实现。

## 用法

1. 从源码构建并运行桌面应用。先构建网页前端（可选示例：`npm ci` / `npm run build`），再在 `src-tauri/`（单独 Cargo 包）里 `cargo build`，或本地开发用 `cargo tauri dev` 后跑构建出的二进制。需要 Tauri 2 系统依赖（Linux：WebKitGTK 4.1 等）。当前不提供安装包。
2. 在应用内管理臂、跑自报 / 敏感性；同意后可手动跑一次探针或看回放，也可启用应用内定时重跑（见功能段）。
3. 可选示例：核心库检查 `cargo test --workspace`；探针 `cargo run -p agent-value-core --example probe_plan` / `probe_judge`。
4. 版本改动见 `CHANGELOG.md`；本 README 不含变更史。
